This release extends jobs from local `ptc submit` to mesh dispatch, and adds a queue, configurable storage locations, disk usage, and local cleanup. It is a pre-release: the Bitswap data plane, SSH install, and `ptc update` are not included yet.

## Added

- `ptc submit --target <node name or peer id>` dispatches a job to a named exec node over `/ptc/exec/1.0.0`. `--target auto` selects a qualified exec node. The default is still a local run.
- Exec nodes have a persistent queue (default concurrency 1). Inspect it with `ptc queue` and cancel with `ptc cancel`.
- Seed / CAS and worktree roots can be configured separately. Cleaning a worktree does not delete the seeds it references.
- Node details (CLI `ptc peers show` and the WebUI Nodes pane) show real disk totals, free space, and ptc usage by category.
- `ptc clean` (CLI only) can clean outputs, run records, and worktrees by id or regexp, and can delete a resource by digest. Use `--dry-run` first to see how much space would be freed; actual deletion requires `--yes`. Pinned items, and items referenced by a queued or running job, are not deleted. Cleanup is local only for now.
- Optional Docker overlay: an official `nvidia/cuda` Ubuntu container as an exec node, used to verify real CUDA jobs. The default live mesh does not mount a fake GPU.

## Download and verify

The assets include Windows, Linux, and macOS amd64 / arm64 binaries (Windows is amd64) and the skill text bound to this version. Verify against `SHA256SUMS` before you run anything. `ptc version` should be `0.2.0-p2`.

The Go module path in this repository is still `github.com/peer-task-control/ptc`, which differs from the GitHub URL. Download the binaries from this page; do not use `go install`.

## Known limits

- P1 Bitswap / filestore / pin, the official complete P3 UI, and P4 first-time SSH install plus mesh upgrades are not implemented yet.
- `ptc clean` applies only locally.
- Dropping a follow connection does not automatically cancel a remote job.

这一版把任务从本机 `ptc submit` 扩展到网格派发，并补上队列、存储位置配置、磁盘占用和本机清理。这是预发布：bitswap 数据面、SSH 安装和 `ptc update` 还没有做。

## 新增

- `ptc submit --target <节点名或 peer id>` 通过 `/ptc/exec/1.0.0` 把 job 派到指定执行节点；`--target auto` 会选择合格的 exec 节点。默认仍在本机执行。
- 执行节点有持久队列（默认同时跑 1 个）；可用 `ptc queue` 查看、`ptc cancel` 取消。
- 种子 / CAS 和 worktree 的根目录可分别配置。清理 worktree 不会删除它引用的种子。
- 节点详情（CLI `ptc peers show` 和 WebUI 节点栏）显示真实磁盘总量、剩余，以及 ptc 各类数据占用。
- `ptc clean`（仅 CLI）可按 id 或正则清理 output、运行记录、worktree，也可按 digest 删除资源。先 `--dry-run` 查看将释放的空间，真正删除需要 `--yes`。已被 pin 或正在被排队/运行任务引用的项不会删。目前只清理本机。
- 可选 Docker overlay：官方 `nvidia/cuda` Ubuntu 容器作为 exec 节点，用于验证真实 CUDA 任务。默认 live 组网不会挂模拟 GPU。

## 下载与校验

附件提供 Windows、Linux、macOS 的 amd64 / arm64 二进制（Windows 为 amd64），以及与该版本绑定的 skill 文本。请用 `SHA256SUMS` 核对后再运行。`ptc version` 应为 `0.2.0-p2`。

本仓库的 Go 模块路径仍是 `github.com/tigeregit/peer-task-control`，与 GitHub 地址不同，请下载本页二进制，不要用 `go install`。

## 已知限制

- P1 bitswap / filestore / pin、官方完整 P3 界面、P4 SSH 首次安装与网格升级尚未实现。
- `ptc clean` 只作用于本机。
- 跟随模式断开连接时不会自动取消远程任务。

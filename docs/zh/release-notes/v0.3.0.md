这一版补上了 Bitswap 数据面、纯做种复制、校验过的 SSH 安装与网格升级、存储配额，以及与版本绑定的 Agent Skills pack。这是 `0.2.0-p2` 预发布之后的第一个正式标签。

## 新增

- Bitswap 数据面：资源摘要发现仍走受信任 PTC 网格，数据按 256KiB 分块通过 Boxo Bitswap 交换，支持中转、校验、持久缓存与副本故障切换。
- 大资源自动使用多层 Merkle 索引，不再受 10,000 块、约 2.44GiB 的固定上限约束；仍受磁盘空间、传输超时和中继连接配额限制。小资源保留 v1 manifest；提供与接收大资源的节点均须升级以支持 v2 索引。
- `ptc resources pull` 把校验后的副本写入本机并通告传输 CID。看板上的 CID 是传输 manifest，不是 UnixFS。
- 纯做种任务：单独的 `ptc/seed@v0` action 获取并公开指定资源集合，不创建 workspace、不执行命令、不打结果包。可下发到只开 files 服务的节点以增加容灾副本。
- `ptc install --ssh HOST`、`ptc update [--ssh HOST|--mesh]` 从官方 Release 下载并校验二进制，替换失败回滚。本机 `ptc update` 会写入 `install.json` 并重启正在运行的 daemon（`--no-restart` 可跳过）。`ptc update --mesh` 向已记录安装且允许远端更新的同主版本节点滚动升级，目标用 Bitswap 拉取二进制。SSH 支持 Linux amd64/arm64、Windows amd64，并保持严格主机密钥校验。
- 存储配额与持久保留；清理种子时会保护仍在使用的 worktree，并遵守工作区配额。
- 全局限速的手动发现扫描；扫描覆盖网卡所在的整个子网，并跳过回环地址。
- 与版本绑定的 Agent Skills pack 位于 `skills/peer-task-control/`。`ptc skill sync` 以及成功的 `ptc update` / `ptc install` 会把它写入 `~/.agents/skills/peer-task-control/`。
- 可部署的 `docker/` 组件、中英双语文档、架构图、CI，以及 issue / PR 模板。
- Go 模块路径现为 `github.com/tigeregit/peer-task-control`，与 GitHub 地址一致。

## 修复

- 本机提交会遵守 `--fetch-result`；发向本机的队列提交也能正确入队。
- 滚动升级更安全、可观察；传输 CID 不再写入种子内容。
- 重连后会恢复 relay reservation；取消操作会一致地收尾。
- 拉取结果时的 JSON 输出保持有效；跨节点不再出现 run ID 冲突。
- 并发 Bitswap 导出复用已校验的块；保存配置时扫描主机缓存保持同步。

## 下载与校验

附件提供 Windows、Linux、macOS 的 amd64 / arm64 二进制（Windows 为 amd64），以及与该版本绑定的 skill 文本和 skill pack 打包文件。请用 `SHA256SUMS` 核对后再运行。`ptc version` 应为 `0.3.0`。

请优先下载本页二进制，不要用 `go install`，以便使用打上 Release 版本号的构建。

## 已知限制

- P1 剩余：UnixFS / filestore、CID / dataset 输入解析、分块缓存 GC。目前 manifest pin 已有，完整 pin 管理尚未提供。
- P3：官方完整产品界面（当前只有只读看板）。
- P4 剩余：操作系统服务安装；SSH 安装仍不写入远端 `install.json`。
- `ptc clean` 只作用于本机（没有 `ptc clean --node`）。
- 跟随模式断开连接时不会自动取消远程任务，需显式 `ptc cancel`。
